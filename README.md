# Story Room · Local Interactive Books

当前版本 **1.3.3**。打开 http://127.0.0.1:8766/?version=tts3 ，点击书架上的奥托或底部阅读卡。

也可以双击「start-story-room.command」。默认端口 8766，保留原来 8765 书房。

## 在线预览

GitHub Pages：https://yymm111.github.io/story-room/

首页、3D 书架、已有故事、40 页内置配音、浏览器内的导入与阅读进度可以在线体验。新增文字的 AI 配音和图片自动识别依赖本地 Python/模型服务，在线预览不提供；新增文字可在设置中切换“系统辅助朗读”。

预览站从 `main` 分支根目录发布。`.nojekyll` 保证素材和脚本按静态文件直接部署，后续更新 `main` 会触发重新发布。

## 从 GitHub 启动与协作

这是独立的 Story Room 网站源码仓库。首次克隆后运行：

```sh
python3 server.py --port 8766
```

打开 http://127.0.0.1:8766/ 。前端依赖、图片、3D 模型和 40 页内置配音已包含，无需安装 npm 依赖或构建。检查 JavaScript 语法使用 `npm run check`（需要 Node.js）。

协作约定、目录入口及可选语音环境安装见 [CONTRIBUTING.md](CONTRIBUTING.md)。`.local/` 内的模型、环境、缓存和开发备份不上传；阅读进度与导入书籍保存在使用者浏览器中。

## 这一版

- 10 幕完整中文重新讲述，依次为暗窗、红气球、屋顶小猫、云海、猫头鹰、星星、云后月亮、月亮露面、下降回家、晚安。它不是原版全文翻译。
- 原站公开免费书的插画、Otto 模型及动作素材用于本地对照；来源、大小和摘要见 REFERENCE_SOURCES.json。未将这些素材称为本项目原创，也未发布到公网。
- 每一页使用本机 Qwen3-TTS-1.7B-4bit / Serena 生成的 MP3，已随项目保存；播放无需连接原站，也无需等待模型启动。
- 角色动作平滑衔接；绳子跟随骨骼手部，气球与身体有不同的风摆节奏；纸艺分层展开、云层让路、月光扩散。
- 可点击场景角色，也可使用右下角动作按钮；点击故事里的相关词，会触发对应动作并从该句朗读。
- 朗读高亮使用语音生成段落边界，段内按字数估计。它不是逐字强制对齐。
- 支持暂停、继续、自动翻页、目录、近看、减少动态效果及原书房的导入功能。

## 本地 TTS

当前机器复用原书房已安装的模型与 Python 环境（.local 下只存本地链接，不进入交付包）。内置十页 MP3 在其他机器也可直接播放。新增文字的即时合成需要本机安装 AI 语音环境，可运行随附安装命令。

启动：`python3 server.py --port 8766`。检查：`npm run check`。
